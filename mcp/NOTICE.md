# MCP attribution

This plugin bundles the built read-only Camptocamp MCP from the public repository:

- Repository: https://github.com/jducerf/mcp-camptocamp
- Snapshot: `910e29bcc97b1ab60d614ad854e82a7bc5ac019c`
- Upstream project: https://github.com/olaurendeau/mcp-camptocamp
- License: MIT

The bundled server is included so Agent Plugins clients can launch it through
the portable root `mcp.json` without using the maintainer's VPS.
